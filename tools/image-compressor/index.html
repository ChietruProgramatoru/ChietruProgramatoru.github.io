How it works

Your browser decodes each image and re-encodes it with the same high-quality encoders used by Google's Squoosh app (MozJPEG, libwebp, libavif and OxiPNG), compiled to run on your own device. Several images are processed at once on separate CPU cores. Location data and other hidden metadata (EXIF) are removed, which also protects your privacy.

FAQ

Is it really free?

Yes. There's no paid tier, no daily limit, no watermark and no account. The work happens on your own device, so it costs nothing to run. If it helps you, a coffee tip is appreciated but never required.

Are my photos private?

They never leave your device. You can even turn off Wi-Fi after the page loads and it still works.

Which format should I pick?

Keep "Same as original" if you're not sure. JPG works everywhere. WebP is about 25 to 35% smaller and great for websites. AVIF is smaller still but a bit slower to make. PNG keeps transparency; with quality below 100 it reduces colors (like TinyPNG) for much smaller files.

How do I get a photo under a size limit (like 200 KB for a form)?

Set "Max file size". The tool tries quality levels until it finds the best one that fits, and shrinks the dimensions only if it has to.

Why did a file say "kept original"?

It was already well compressed. Rather than hand you a bigger file, the tool keeps your original.

Can I install it?

Yes. In Chrome or Edge use "Install app" in the menu; on iPhone use Share → Add to Home Screen. It then works offline.
